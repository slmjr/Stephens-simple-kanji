# Changelog

## 1.1.0 — 2026-08-10

- Replaced 2,000 unreliable generated mnemonic stories with data-grounded memory aids.
- Added per-kanji content reports with a GitHub Issues integration point.
- Added a seven-day review forecast and 28-day study activity calendar.
- Added weak-item detection for repeatedly missed kanji.
- Tightened meaning matching to avoid accidental substring matches.
- Clarified simplified vocabulary part-of-speech labels.
- Made Ko-fi the primary support option and collapsed cryptocurrency details.
- Moved dashboard donation prompts behind meaningful study milestones.
- Split maintainable source, data, styles, and build scripts while preserving `index.html` as a single-file distribution.
- Added release metadata, issue templates, funding configuration, and automated checks.
- Added a session-only fallback when a browser blocks storage, preventing the onboarding button from becoming stuck.
- Fixed completed lessons so progress is saved immediately rather than only after an entire lesson batch.
