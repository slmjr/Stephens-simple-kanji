# Memory-aid guidelines

The app's built-in memory aids must help recall without presenting invented stories as character history.

## Required qualities

- Base the aid on the displayed kanji, primary meaning, listed reading, or bundled vocabulary.
- Label visual imagination as a memory cue, not etymology.
- Prefer a real vocabulary anchor over a loose English sound-alike.
- Keep the aid short enough to review quickly.
- Avoid claims about radicals, historical forms, or origins unless a reliable source is cited.
- Avoid cultural stereotypes, violent imagery, and embarrassing material.

## Current system

Version 1.1 replaced the original 2,000 generated stories with a consistent data-grounded system. It combines:

1. an explicitly labelled visual cue when a safe one is available;
2. the primary displayed meaning;
3. the first listed reading; and
4. a real bundled vocabulary example.

Learners can save a private personal memory aid for every kanji. Content reports should be used to propose carefully reviewed built-in improvements.
